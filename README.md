# Matekservice A1.0 Oficial — PC + Celular

Versão consolidada para um único endereço de acesso em PC e celular.

Ajustes desta revisão:
- relatório exibe “Nº do relatório” em vez de “Relatório / OS”;
- layout responsivo reforçado para telas pequenas e uso por toque;
- campos e botões maiores no celular;
- fotos podem ser escolhidas da câmera, galeria/Google Fotos ou arquivos, conforme opções oferecidas pelo aparelho;
- mantém numeração automática sequencial por cliente e compatibilidade com os dados/backup da A1.0.

Para publicação, envie o conteúdo desta pasta para um endereço web HTTPS estável.
